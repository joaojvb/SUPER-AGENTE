# SUPER-AGENTE — Universal Studio Agent (28 Áreas · Padrão OMEGA v4.0)

Um **Estúdio Completo de 28 Especialistas** (Engenharia, Ponte Técnica, Direção de Arte `AETHER-OMEGA v4.0`, Visual, Áudio, Produto e QA) unificado em um Agente Universal Adaptativo de baixo custo de tokens.

---

## ⚡ Instalação em 1 Comando (Em Qualquer Projeto Novo ou Antigo)

Qualquer pessoa pode injetar o **SUPER-AGENTE** dentro da pasta do seu próprio projeto rodando apenas 1 linha no terminal:

### Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/joaojvb/SUPER-AGENTE/main/install.ps1 | iex
```

### Linux / macOS / Git Bash:
```bash
curl -fsSL https://raw.githubusercontent.com/joaojvb/SUPER-AGENTE/main/install.sh | bash
```

### Ou Clonando Direto:
```bash
git clone https://github.com/joaojvb/SUPER-AGENTE.git
```

Assim que os arquivos caem na pasta, os ativadores automáticos (`AGENTS.md`, `CLAUDE.md`, `.cursorrules` e `SKILL.md`) fazem a IA assumir imediatamente a mente do Estúdio Completo sem precisar configurar nada.

## Por que este Agente é Diferente?
1. **Contra a "Qualidade Rasa do Comando Único":** Em vez de tentar fazer um projeto inteiro de uma vez entregando 20% de qualidade em tudo, o Super-Agente fatia o projeto e entrega **100% da capacidade da IA em cada parte** (Lógica -> Direção de Arte & UI -> Áudio & VFX -> Auditoria Tripla de QA).
2. **Especificação Nível OMEGA v4.0 nas 28 Áreas:** Cada uma das 28 profissões possui seu próprio protocolo **Zero-Slop** (proibição de práticas amadoras), matrizes técnicas, física/engenharia real e **Gold Standard Benchmark** (comparação entre saída amadora proibida e saída OMEGA obrigatória).
3. **Contra o "Usuário Perdido":** A pessoa só precisa ter a ideia. O agente cria automaticamente o **Plano de Ação Adaptativo** (`core/project-adaptive-blueprint.md`) e guia o usuário passo a passo com o *Painel de Navegação*.
4. **Pronto de Fábrica + Auto-Absorção Zero-Esforço:** Já vem pré-alimentado nas 28 áreas e nos cofres de estilo, código, som e QA. E se o usuário jogar uma imagem ou código solto no chat (sem explicar regras), a própria IA deduz os padrões técnicos e aprende sozinha.
