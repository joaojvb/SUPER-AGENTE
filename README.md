# SUPER-AGENTE — Universal Studio Agent (28 Áreas)

Um **Estúdio Completo de 28 Especialistas** (Engenharia, Ponte Técnica, Direção de Arte & Visual, Áudio, Produto e QA) unificado em um Agente Universal Adaptativo de baixo custo de tokens.

## Por que este Agente existe?
1. **Contra a "Qualidade Rasa do Comando Único":** Em vez de tentar fazer um projeto inteiro de uma vez entregando 20% de qualidade em tudo, o Super-Agente fatia o projeto e entrega **100% da capacidade da IA em cada parte** (Lógica -> Direção de Arte & UI -> Áudio & VFX -> Auditoria Tripla de QA).
2. **Contra o "Usuário Perdido":** A pessoa só precisa ter a ideia. O agente cria automaticamente o **Plano de Ação Adaptativo** de acordo com o tipo de projeto (App, SaaS, Jogo 2D/3D, Site) e guia o usuário passo a passo com o *Painel de Navegação*.
3. **Pronto de Fábrica + Auto-Absorção Zero-Esforço:** Já vem pré-alimentado nas 28 áreas e nos cofres de estilo, código, som e QA. E se o usuário jogar uma imagem ou código solto no chat (sem explicar regras), a própria IA deduz os padrões técnicos e aprende sozinha.
